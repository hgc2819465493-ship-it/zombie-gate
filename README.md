# 肥嘟嘟打丧尸

手机广告同款「过门加成打丧尸」小游戏。单文件 HTML，打开就能玩。

## 玩法

- **滑动左右**（或 A/D、方向键）控制蓝色小队
- **自动向前跑、自动射击**
- 走过 **蓝色门** `+` / `×` 变强，躲开 **红色门** `−` / `÷`
- 射击可以给 `+` / `−` 门充能，数字会变大；把红色 `−` 打满会变成蓝色 `+`
- 绿色丧尸碰到你会掉兵力；打到金币
- 关底金色首领，打爆过关
- 关卡间用金币升级：初始兵力 / 火力 / 射速（本地保存）

## 打开

直接用手机或电脑浏览器打开 `index.html`，或访问 GitHub Pages。

## 技术

纯 Canvas + WebAudio，无依赖、无联网资源。
